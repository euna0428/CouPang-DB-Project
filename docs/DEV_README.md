# 쿠팡 물류센터 근무·급여 관리 DB 설계 (데이터베이스이론 및 실습 기말 프로젝트)

- 개인 프로젝트 / MySQL, SQL
- 요구사항 분석 → 개념 설계(ERD) → 논리 설계 → 물리 설계 → 구축
- 테이블: 알바생, 물류센터, 업무, 근무(외래키 3개로 연결)
- SQL 25문제: 조건 조회, 정렬, 집계(COUNT·SUM·AVG·GROUP BY·HAVING), 4개 테이블 JOIN, 서브쿼리

## 파일
- DataBase-Project-CouPang.sql : 테이블 생성, 샘플 데이터 입력, 25개 쿼리
- CouPang_DB_Project.pdf : 최종 발표 자료

## 한계와 개선 방향
- 데이터는 학습용 샘플입니다(알바생 3명, 근무 6건).
- 전화번호를 INT로 저장해 앞자리 0이 사라지므로 CHAR로 바꿔야 합니다.
- 근무날짜·시간을 문자열로 저장했으므로 DATE·TIME 타입으로 바꾸면 근무시간 계산이 가능합니다.
