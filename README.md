# 쿠팡 물류센터 근무·급여 관리 DB 설계

물류센터 알바생의 근무와 급여를 관리하는 데이터베이스를 요구사항 분석부터 설계·구축·SQL 작성까지 진행한 프로젝트입니다. (데이터베이스이론 및 실습 기말 개인 프로젝트)

## 작업 정보

| 구분 | 내용 |
|---|---|
| 작업 기간 | 2026.03.09 ~ 2026.06.08 (최종 발표 2026.06.17) |
| 작업 인원 | 1명 (개인 프로젝트) |
| 내 역할 | 요구사항 분석, 개념·논리·물리 설계, SQL 작성 |
| 작업 툴 | MySQL, SQL, MySQL Workbench |

## 작품 소개

쿠팡 물류센터의 알바생·물류센터·업무·근무(급여) 정보를 관리하는 DB입니다. 요구사항 분석 → 개념 설계(ERD) → 논리 설계 → 물리 설계 → 구축 순서로 진행했습니다.

## 내가 한 일

- 알바생·물류센터·업무·근무 **4개 테이블**을 설계했고, 근무 테이블에 **외래키 3개**를 두어 테이블 간 관계와 데이터 무결성을 확보했습니다.
- MySQL Workbench에서 PK·FK·NOT NULL 제약을 포함한 테이블을 생성하고 샘플 데이터를 입력했습니다.
- **SQL 25문제**를 직접 작성·실행했습니다.

| 분류 | 사용한 문법 |
|---|---|
| 조건 조회 | WHERE, LIKE |
| 정렬·중복 | ORDER BY, DISTINCT |
| 집계 | COUNT, SUM, AVG, GROUP BY, HAVING |
| 다중 테이블 | 최대 4개 테이블 JOIN |
| 중첩 | 서브쿼리 |

## 결과

- 알바생별·센터별 급여 합계를 구하는 집계 쿼리와 다중 JOIN 쿼리의 결과를 직접 검증했습니다(학습용 샘플 데이터 기준).
- 외래키 설계가 데이터 무결성의 핵심이라는 점을 이해했습니다.

## 한계와 개선 방향

- 데이터는 학습용 샘플입니다(알바생 3명, 근무 6건). 실제 규모의 데이터로 집계 성능이나 분석을 검증하지는 못했습니다.
- 전화번호를 INT로 저장해 앞자리 0이 사라지므로 CHAR로 바꿔야 합니다.
- 근무날짜·시간을 문자열로 저장했으므로 DATE·TIME 타입으로 바꾸면 근무시간 계산이 가능합니다.
